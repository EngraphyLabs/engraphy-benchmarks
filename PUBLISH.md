## Dataset licences and reporting figures

### LoCoMo, CC BY-NC 4.0: the position

LoCoMo (Maharana et al., ACL 2024, `snap-research/locomo`) is licensed CC BY-NC 4.0.
The position this repository takes, decided by the owner on 2026-10-15:

**Reporting a measured score, with attribution, is not redistributing the dataset.**

- **What the licence governs.** CC BY-NC 4.0 governs sharing and adapting the
  licensed material: the conversations, the questions and the gold answers. A
  score is a measurement of Engraphy. It is a fact about how a system performed,
  and it contains none of the licensed material.
- **What is never published.** No LoCoMo text appears in this repository or in
  any figure: no conversation, no question and no gold answer. Committed results
  carry question ids, categories, verdicts and Engraphy's own answers.
  `reproduce.py` downloads the file from its authors, and CI refuses a committed
  `locomo10.json`. Anyone who reruns the measurement takes the data under its own
  licence, from its source.
- **What is not resolved.** Running the benchmark copies the dataset locally, and
  that copy is use of the licensed material. Whether an internal measurement made
  by a commercial project is non-commercial use is a question the licence does
  not answer directly. Two options remove the residual question entirely: the
  dataset authors' permission, or confining the figures to research-framed
  material. The question is recorded here so that the stance above is taken
  knowingly. This is a recorded decision, not legal advice.

**Attribute wherever a LoCoMo figure appears.** On the website, in comparison-site
submissions, in decks and in posts, every LoCoMo figure carries a line like this
one, or an equivalent:

> Measured on LoCoMo (Maharana et al., "Evaluating Very Long-Term Conversational
> Memory of LLM Agents", ACL 2024), licensed CC BY-NC 4.0. The dataset is not
> redistributed.

Where space is short, "LoCoMo (Maharana et al., 2024), CC BY-NC 4.0" with a link to
`https://github.com/snap-research/locomo` is the minimum.

### Other benchmarks

**None of the candidate benchmarks restricts reporting a measured score.** The
survey is in `analysis/2026-10-15-benchmark-expansion-plan.md`.

| benchmark | licence | effect on reporting a score |
|---|---|---|
| LongMemEval (`xiaowu0162/longmemeval-cleaned`) | MIT | none; attribute the paper (Wu et al., ICLR 2025) |
| BEAM | CC BY-SA 4.0 | none; share-alike binds redistributing the data, not a score |
| PersonaMem | MIT | none |
| PerLTQA | CC BY-NC 4.0, "non-commercial research use only" | the same question as LoCoMo, stated more narrowly; it is not run here |
| DMR (`MemGPT/MSC-Self-Instruct`) | Apache-2.0 on the derived set; the underlying MSC data licence is not stated anywhere found | unresolved; not run here |

LongMemEval's files contain text generated by GPT-4o and Llama 3. Those model
providers' terms restrict using outputs to train competing models. They do not
restrict reporting an evaluation score.
